# Evals — make-skill

This folder captures evaluation artefacts for the `make-skill` skill.

## What to record here

After each weekly skill health review, add entries for:

- **Golden examples** — session excerpts where the skill worked well; useful as positive anchors
- **Failure notes** — brief description of what went wrong, what the skill should have done differently
- **Hypothesis log** — your tested hypothesis + outcome after a skill update

## File conventions

```
evals/
├── README.md          # This file
├── golden/            # Optional: excerpts of successful usage
└── failures/          # Optional: failure case notes
```

Add dated entries: `failures/2026-05-30-missed-activation.md`
